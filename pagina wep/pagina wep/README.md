# Proyecto de Página Web de Gatos

Este repositorio contiene una página web simple estática sobre razas de gatos, con diseño responsivo y contenido visual.

## 📁 Estructura de archivos
- `index.html` - Página principal con introducción y navegación.
- `gatos.html` - Página secundaria con lista/galería de razas de gatos.
- `style.css` - Estilos CSS para diseño, colores y responsividad.
- `razas-de-gatos.avif` - Imagen usada como recurso visual en la web.
- `README.md` - Documentación del proyecto.

## ⚙️ Tecnologías usadas
- HTML5
- CSS3
- Formato de imagen AVIF

## 🚀 Cómo ejecutar
1. Abre la carpeta del proyecto en tu editor (por ejemplo, VS Code).
2. Abre `index.html` en el navegador (doble clic o "Open with Live Server").
3. Navega a la página de gatos usando los enlaces o el menú.

## 🛠️ Cómo mejorar o contribuir
- Añade más razas en `gatos.html` con una tarjeta de imagen + descripción.
- Ajusta estilos en `style.css` para colores, tipografía y diseño responsivo.
- Si agregas JavaScript, crea un archivo `script.js` y actualiza el HTML.

## ✅ Notas
- Este sitio es estático, no requiere servidor. Se puede desplegar en GitHub Pages u otros hosts estáticos.
- Asegúrate de que el archivo `razas-de-gatos.avif` tenga ruta correcta si mueves la estructura.
